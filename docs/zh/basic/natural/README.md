## 学习路径

建议按照以下顺序阅读文档：

1. 首先阅读[理论简介](01_introduction.md)，获取对理论的整体理解
2. 其次阅读[基本概念](02_basic_concepts.md)，掌握核心术语和定义
3. 然后阅读[理论框架](03_theoretical_framework.md)，理解理论的结构与公理
4. 再深入到[观察者与意识](05_observer_and_consciousness.md)等具体主题
5. 最后探索其他专题文档，如命运与自由意志、量子纠缠本质等

每个文档都建立在前序文档的基础上，形成渐进的学习路径，帮助读者从基础到深入全面理解量子经典二元论。
