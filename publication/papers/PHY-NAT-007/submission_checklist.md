# Submission Checklist for Nature Physics

## Manuscript Components

- [x] Title and running title
- [x] Author list and affiliations
- [x] Abstract (≤150 words)
- [x] Main text (3,000-4,000 words)
- [ ] References (formatted according to Nature Physics style)
- [ ] Figure legends
- [ ] Figures (high-resolution)
- [ ] Tables

## Supplementary Materials

- [ ] Mathematical appendices
- [ ] Detailed derivations
- [ ] Simulation code documentation
- [ ] Additional figures
- [ ] Extended methods

## Submission Documents

- [x] Cover letter
- [x] Author information
- [x] Research highlights
- [ ] Competing interests statement
- [ ] Data availability statement
- [ ] Code availability statement
- [ ] Funding information
- [ ] Author contribution statement
- [ ] Reviewer suggestions

## Format Requirements

- [ ] Main text in .docx or .tex format
- [ ] Figures in .eps, .pdf, or .ai format (min 300 dpi)
- [ ] All figures cited in text
- [ ] All references cited in text
- [ ] Equations numbered sequentially
- [ ] Units conform to Nature Physics style
- [ ] Abbreviations defined at first mention

## Final Checks

- [ ] Spell check completed
- [ ] Grammar check completed
- [ ] All authors have approved the final version
- [ ] All files named according to naming convention
- [ ] File sizes within submission limits
- [ ] All supplementary material properly referenced in main text
- [ ] Confirmation of originality and ethical compliance

## Post-Submission Plan

- [ ] Prepare for potential reviewer comments
- [ ] Identify areas that may need clarification
- [ ] Begin planning follow-up experiments
